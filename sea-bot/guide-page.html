Admin guide

  • How to activate SCB in the right group

    Go to the desired group, add a new user SCB, and make it a group admin.

    Go to the admin panel and check the box next to the desired group. SCB will then manage access to this group and start scanning participants. This means that when SCB is the group admin, new participants can only be added to the group through SCB (see below). If a participant joins the group via an invitation link, bypassing SCB, SCB will automatically remove that participant from the group. This does not apply to existing group participants, only new ones.

  • How to change the individual welcome message for new members

    When new members register, SCB displays a message with a list of groups and a short description of them. This message can be set up in the admin panel.

  • How to approve members

    Send an SCB link to the potential group members and ask them to activate it: all of them need to fill in corporate information such as first name, last name, company website and position.

    There is no sensitive information such as phone number. For current group members, ask them to fill in the same information, and they will appear in the admin panel as approved members.

    All group applications are displayed in your admin panel.

    A decision should be made for each application:

    - approve – SCB adds the member to the group and introduces the new member to all others

    - decline – the application is rejected, although the person can reapply.

    - block – the person cannot reapply for membership; they would need to be unblocked to do so.

  • How to remove members from groups

    In the admin panel find the desired user by ID or username and click "exclude" next to each group of which he is a member.

    The SCB will remove him immediately.

  • How to block the entire SCB for an individual member

    In the admin panel in the last column, mark the desired user as blacklisted, then click save.

  • How to send an individual message to all group members

    In the admin panel click "add mass mailing," enter the text of the message, check "start mailing," and click "save."

    The message will be sent to all members whose sites have green verification.

    They will receive a personal message from the SCB.

    You can see who it was sent to in the admin panel.

  • How to set the order of the buttons in the group list

    When you click "join groups" in SCB, their list is shown in the form of buttons in random order. The group buttons can be put in a specific order in the admin panel by entering the desired order number against the name of the group (the "No. in the menu" column). It is important that the names of groups not be too long, otherwise the button will not fit the entire name. The recommended length of the group name is no more than 27 characters, including spaces.

  • How to export a list of companies from the SCB

    In the admin panel, click "export to CSV" and open it as follows:

    - create or open an empty document in Google Sheets https:// www.google.com/sheets/about/

    - select File, Import, Load from Google Sheets and select the CSV file previously exported

  • How to import a list of companies into SCB

    - create or open an empty document in Google Sheets https:// www.google.com/sheets/about/

    Title the first 4 columns:

    Company name, Website link, Profile link, City

    Fill in data into the table, then go to Menu, Download, and choose CSV format.

    Open the admin panel, click on "Import from CSV" and download the prepared CSV file. The data to be downloaded is in addition to the data already present in the SCB.

  • How to export a member list from SCB

    In the admin panel click "export to CSV" and open the file as follows

    - create or open an empty document in Google Sheets https:// www.google.com/sheets/about/

    - select File, Import, Upload from the Google Sheets menu and select the CSV file you previously exported

    Fill in data into the table, then go to Menu, Download, and choose CSV format.

    Open the admin panel, click on "Import from CSV" and download the prepared CSV file. The data to be downloaded is in addition to the data already present in the SCB.

  • How to export a member list from SCB

    In the admin panel click "export to CSV" and open the file as follows

    - create or open an empty document in Google Sheets https:// www.google.com/sheets/about/

    - select File, Import, Upload from the Google Sheets menu and select the CSV file you previously exported

  • How to import a member list into SCB

    IMPORTANT!!!
    Before importing contacts SCB must be added to all groups you want.

    - Create or open an empty document in Google Sheets https:// www.google.com/sheets/about/

    Title the first 7 columns:

    ID, First Name, Last Name, Telegram username, Website, Position

    Fill the data table, then select Menu, Download, and choose the format CSV. Members without an ID value will not be loaded. All uploaded data supplements already existing data in the SCB.

    Open the admin panel, click "Import from CSV" and download the prepared CSV file.

Guide for members

  • In what situations can SCB be useful

    1. When you and another person are strangers—that is, you are not in each other's notebooks, but you share one or more groups, and you want to know who the other person is.

    2. When you only know someone’s username, but want more information.

    3. When you do not have any information other than a group message from a person of interest, but you want more information.

    4. When you need to find representatives of a specific company in a company group.

    5. When you need to know the groups in a company, which of them you are already a member of, and which you have not yet joined.

  • General description

    Information about a person can be searched according to any of the following parameters:

    - user

    - username (username) in Telegram

    - company website

  • SCB working conditions

    1. You and the SCB are together in one or more company groups.

    2. You filled in the primary information about yourself through SCB: first name, last name, position and company website.

  • How to activate SCB

    Find SCB in the global Telegram search or in the list of group members named *****. You can also use the direct link ******.

  • Open SCB and enter into correspondence with it

    After starting the SCB, you must click on the "START" button

    A welcome text will appear with a general description of the SCB capabilities. You need to click on the "Start" button

    The SCB will sequentially request information about you: first name, last name, position and company website.

    When you fill in all the information about yourself, SCB will show it to you in the form in which other company members will see it when searching. Click on the "Finish" button, the information will be saved on our server and SCB will be activated for you.

  • How to join company groups

    Access to groups becomes available only after activating the SCB (see How to activate SCB).

    After activation, the SCB will send you a description of the groups that are available to you. Read the list of groups carefully and choose those that are of most interest to you. In the SCB menu, click "Join Groups" and follow the instructions.

    For each group button, there are current statuses that you can have (written opposite each group name):

    "apply" means that you are not in the group yet

    "application pending" - means that your application for membership is under consideration by the group administrator

    "You are a member" means that you are already a member of the group

    "blocked" - means that for some reason the administrator has blocked you from joining the group

    After the approval of the application for membership, SCB automatically adds you to the group and introduces you to the current participants in the format: #new member First name Last name, position, company website.

  • How to search for information about members through SCB

    The easiest and fastest way is to forward any message of the member you are interested in to SCB. In the response message, the SCB will send information about the member of interest in the following format

    First name:

    Last name:

    Position:

    Company website:

    Username:

    Company name:

    City:

    If this member has logged out of all company groups, then his data will not be searchable.

    Through the SCB menu, you can search using 2 parameters:

    Search by name (username) in Telegram means that you can find a member by a complete match of his username. Only 1 issue per search. Click on the "Search by name" button and follow the instructions.

    Site search means that you can search for several employees of 1 company on the site of this company. A search must have at least 5 characters. In the issue there will be no more than 3 random contacts per search. Click on the "Search site" button and follow the instructions.

  • How to edit information about yourself

    You can change your information at any time. When it may be required:

    - a typo or mistake was made during the initial filling of data about yourself;

    - the position or site of the organisation has changed;

    Find the SCB in the global Telegram search or in the list of group participants named ****.

    Open the SCB and start chatting with it.

    After starting the SCB, you must click on the "START" button.

    In the main menu that appears, click on the "About me" button.

    SCB will give you the current information about yourself. Click on the "Edit" button.

    Choose what you want to edit:

    edit first name

    edit last name

    edit position

    edit the site (meaning the site of the company you represent).

    You can check how SCB shows information about you to other group members by simply forwarding any of your messages to SCB.

  • Blacklist group members. These members can’t use SCB for searching information about other members in your groups.

  • Approve/disapprove new group members using a single admin control panel.
  • Admin members to SCB registration by whitelisting (verified) company websites.
  • Mass messaging via SCB to members with a verified website.
  • Mass upload and download of company list (website, name, city, link to company profile on association website).
  • Mass upload and download of member list (first name, last name, position, company website, Telegram ID, group IDs the user is a member of).
  • Enrich the information with additional data on companies and participants pre-loaded into the database.
